# Stargazers Log

A personal dashboard for tracking the GitHub repositories you've starred.

## Features

- Search by repository name, owner, language, or description
- Filter by category such as frontend, backend, learning, tools, and database
- Sort by newest, oldest, name, or language
- Refresh data directly from the GitHub starred API
- Add, edit, and delete custom entries
- Keep everything saved in `localStorage`

## Run locally

Open `index.html` in a browser, or serve the project with any static file server.

## Notes

This project is intentionally lightweight and runs without a build step.
